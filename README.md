# ShapeBuilder Procedural Bridge Tutorial Assets

Demo assets for the ShapeBuilder 3.1 procedural bridge tutorial in Unity 6.

This repository contains the Unity scene, profiles, materials, procedural pillars, placeholder street lights, and animated traffic setup used in the tutorial.

## Requirements

- Unity 6
- ShapeBuilder 3.1 or newer
- Git LFS when cloning the repository

ShapeBuilder is required and is not included in this repository.

- Website: https://shapebuildertool.com/
- Unity Asset Store: https://u3d.as/3sSE

## Installation

1. Install ShapeBuilder in your Unity project.
2. Clone or download this repository.
3. Copy the `Tutorial` folder into your project's `Assets` folder.
4. Open `Tutorial/1. Bridge/Bridge.unity`.

## Included Content

- Procedural bridge scene and prefabs
- ShapeBuilder 2D profiles
- Procedural bridge pillars
- Placeholder street lights made from Unity primitives
- Spline-based animated traffic setup
- Materials, textures, lightmaps, and reflection data
- Quaternius Cars Pack assets under the CC0 1.0 license

The audio tracks used in the promotional video are not included.
